# 게임 소개

## 이 게임은 무엇인가

4명이 함께 플레이하는 2D 물리 기반 협동 게임입니다. 네 명의 플레이어가 하나의 로봇(사람 모양 관절 캐릭터)을
나눠서 조종합니다 — 각자 팔 하나 또는 다리 하나씩만 담당합니다.

- 플레이어 1: 왼쪽 다리
- 플레이어 2: 오른쪽 다리
- 플레이어 3: 왼쪽 팔
- 플레이어 4: 오른쪽 팔

한 사람이 어디로 뻗을지 정하면, 그 힘이 몸통 전체의 균형과 이동에 영향을 줍니다.
네 명이 손발을 맞추지 못하면 로봇은 그대로 넘어집니다.

로봇은 오른쪽 방향(->)만 바라보기 때문에, 뒤를 돌아볼 수 없습니다.

## 게임의 목적

로봇이 쓰러지지 않고 걷거나 원하는 방향으로 이동하도록, 네 명이 각자 맡은 팔다리를 협력해서 움직이는 것이
핵심입니다. 정해진 승패 조건보다는, 서로 다른 사람이 조종하는 팔다리 네 개를 하나의 몸처럼 맞춰 움직이는
과정 자체가 게임의 재미입니다. (걷기, 균형 잡기, 넘어짐 회복 등 구체적 목표는 아직 설계/개발 진행 중)

## 조작 방법

- 각 플레이어는 자신의 마우스 커서 위치로 담당 팔 또는 다리를 조종합니다.
- 다리를 맡은 플레이어는 발을 어디에 디딜지(마우스 위치)를 정해서 로봇이 걷거나 버티게 만듭니다.
- 팔을 맡은 플레이어는 팔을 뻗는 방향으로 몸통의 기울임(균형)에 영향을 줍니다.
- 별도의 키보드 입력 없이, 마우스 위치만으로 팔다리의 자세가 실시간으로 결정됩니다.
- 호스트가 로비에서 Play를 누르면 참가 순서대로 왼쪽 다리 → 오른쪽 다리 → 왼쪽 팔 → 오른쪽 팔 순으로 역할이 배정됩니다.
