# 로봇 물리 설정

물리 관절형 로봇([Robot.cs](../Assets/Scripts/Robot/Robot.cs), `Assets/Resources/Prefabs/Robot/*.prefab`)의
조작감을 결정하는 값들을 정리하는 문서입니다. 관절 구현 자체는 아직 진행 중이며, 아래 항목은 현재 프리팹에
설정된 실제 값을 기준으로 "무엇이 비어 있는지"를 정리한 것입니다. 실제 수치는 팀에서 테스트하며 채워야
합니다.

## 현재 상태 (코드/프리팹 기준, 2026-08-14 확인)

`Robot.prefab`, `Arm.prefab`, `Leg.prefab`의 `HingeJoint2D` / `Rigidbody2D`는 아직 기본값 그대로입니다.

| 항목 | 현재 값 | 위치 |
| --- | --- | --- |
| 관절 회전 제한 (`m_UseLimits`) | 꺼짐 (0) | Arm.prefab, Leg.prefab의 모든 `HingeJoint2D` |
| 회전 각도 범위 (`m_LowerAngle` / `m_UpperAngle`) | 0 ~ 359 (사실상 무제한) | 위와 동일 |
| 모터 (`m_UseMotor`) | 꺼짐 (0) | 위와 동일 |
| 모터 속도/힘 (`m_MotorSpeed`, `m_MaxMotorTorque`) | 0 | 위와 동일 |
| 부위별 무게 (`Rigidbody2D.m_Mass`) | 몸통/팔/다리 전부 1 (구분 없음) | Robot.prefab, Arm.prefab, Leg.prefab |
| 충돌 레이어 (`m_Layer`) | 전부 `Default`(0), 자기 충돌 방지용 레이어 없음 | 모든 파츠 |

즉 지금은 관절이 끝없이 돌아가고, 모터 힘이 없어 외부 힘(중력 등)에만 반응하며, 몸통과 팔다리가 모두 같은
레이어라 자기 몸과 충돌할 수 있는 상태입니다. 아래 표는 이 값들을 정할 때 채워야 할 항목입니다.

### 4. 자기 몸과의 충돌 여부

**결정됨: 자기 몸통끼리는 관통 가능 (충돌 안 함).** 자유로운 포즈를 취해야 하므로 팔다리와 몸통, 팔다리와
팔다리는 서로 충돌하지 않습니다. 대신 관절(`HingeJoint2D` 연결)이 끊어지거나 어긋나지 않고 항상 잘
붙어 있는 것이 중요합니다.

- 구현 방향: 로봇의 모든 파츠(몸통/상완/전완/허벅지/정강이)를 `Default`가 아닌 전용 레이어(예:
  `Robot`)에 배치하고, `Physics2D` 충돌 매트릭스에서 `Robot`끼리의 충돌을 꺼둡니다. 로봇과
  바닥/장애물 등 외부 오브젝트와의 충돌은 그대로 유지합니다.
- 남은 확인 사항: 여러 로봇(다른 팀/다른 방)이 같은 씬에 존재할 경우, 로봇끼리는 충돌해야 하는지
  아니면 그것도 무시할지 — 현재는 로봇이 하나뿐이라 아직 해당 없음.
- 관절이 "잘 연결"되어야 한다는 요구사항은 회전 범위/모터 힘(위 1, 2번) 튜닝과 직결됩니다: 모터 힘이
  너무 약하거나 각도 제한이 없으면 관절이 늘어지거나 팔다리가 축 늘어진 것처럼 보일 수 있습니다.

### 5. 왼쪽 발 마우스 추종 초기값

왼쪽 아랫다리의 발목 위치에 `TargetJoint2D`를 실행 중 추가하고, 목표 위치를 마우스의 게임 월드 좌표로
갱신합니다. 발은 아랫다리의 자식 콜라이더이므로 별도의 `Rigidbody2D`나 손목 관절을 사용하지 않습니다.

| 항목 | 초기값 | 비고 |
| --- | --- | --- |
| 최대 힘 (`maxForce`) | 1000 | 테스트하며 조정할 임시 값 |
| 흔들림 억제 (`dampingRatio`) | 0.7 | 0~1 범위 |
| 목표를 따라가는 강도 (`frequency`) | 5 | 값이 클수록 더 빠르게 목표를 따라감 |
| 최대 길이 여유 (`reachMargin`) | 0.15 | 다리가 완전히 펴져 몸통을 당기지 않도록 남기는 거리 |

다리가 닿을 수 있는 최대 길이는 생성 당시 골반부터 발목까지의 거리로 자동 계산합니다. 마우스가 이 범위를
벗어나면 목표 위치를 최대 길이 안으로 제한합니다.

현재는 기능 확인을 위해 로컬 마우스가 왼쪽 발을 항상 조종합니다. Photon 플레이어 역할과 입력 권한 연결은
아직 구현되지 않았습니다.
